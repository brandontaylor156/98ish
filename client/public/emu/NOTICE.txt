Files in this folder

games/doom.jsdos     DOOM v1.9 shareware (id Software, 1993-1995), the unmodified files of
                     the official shareware release doom19s.zip (/idgames: idstuff/doom),
                     which says "SHAREWARE VERSION ... PLEASE DISTRIBUTE!!!". The shareware
                     README.TXT, LICENSE terms and ORDER.FRM are included in the bundle.
games/heretic.jsdos  Heretic v1.2 shareware episode (Raven Software / id Software, 1994-1995),
                     the unmodified files of htic_v12.zip (/idgames: idstuff/heretic), which
                     says "FREELY DISTRIBUTE". LICENSE.DOC and VENDOR.DOC are included.
                     (Each bundle adds only a DOSBox config, .jsdos/dosbox.conf.)
vm/freedos722.img    A FreeDOS boot floppy (from the v86 project's demo images). FreeDOS is
                     free software, mostly GPL; sources: https://www.freedos.org

vm/vgabios.bin       LGPL VGABIOS (Bochs/v86), LGPL-2.1, from the v86 repository
