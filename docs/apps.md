# Everyday apps: Address Book, Notes & Tasks, Weather, Camera + Photos, Calendar + Clock
Moved from CLAUDE.md on 2026-10-05.

  - **Address Book** (`applets/addressbook/`, Accessories also Community, `wab`): contacts in `utils/contacts.js` (localStorage `98ish.contacts`, per user; synced per 98 Messenger account through `server/contacts` at `/api/contacts` (bearer token, MongoDB `addressbooks`, per-contact newest-wins merge with tombstones, 2000 contacts / 2 MB / 80 KB pictures); a book synced with another account is set aside in `98ish.contacts.acct.<key>`), rules in `utils/contactsCore.js`, vCard in `vcard.js` (iPhone/Google/Outlook 2.1 QP/4.0 in, 3.0 out). Buddies show as contacts; Buddy List right-click "Add to Address Book"; IM/Call/Video/Mail/Invite to Calendar from a card; Mail To/Cc suggest contacts and offers "Add to Address Book" for senders; Calendar's read-only "Birthdays" calendar (`BIRTHDAYS_ID`, yearly all-day events, reminder at 9:00 on the day); `.vcf` files (type `vcard`) open into Import; "Import from phone" uses the Contact Picker (Android Chrome) and explains the Share Contact > Save to Files way on iPhone. Other apps open it with `launch("Address Book", { handoff: { id, contactId | newContact | importFile | find } })` or `openCouples("Address Book", { handoff })`.
  - **Notes & Tasks** (Accessories; Notes also in Us; desktop icons; DOS `notes`/`stickies`/`tasks`/`todo`; help topics `notes`, `notes-sharing`, `tasks`):
    - **Notes** (`applets/notes/`: `Notes.jsx` list + `NoteEditor.jsx` + `Checklist.jsx` (drag grip with pointer events, Enter/Backspace, Alt+Up/Down; exports the 98 `Tick` box) + `DeskNotes.jsx` + `NotesBridge.jsx`; store `utils/notes.js`; rules `notesCore.js`, also loaded by the server). A note is a set of registers `{ v, t }` (title, body, color, trashedAt) plus checklist `items` keyed by id, each newest-wins with tombstones; `mergeNotes` is commutative/idempotent and `sameNote` compares key-order-independently. Kept in localStorage `98ish.notes` (per user; saves 250 ms after typing, flushed on pagehide); pinned-to-desktop positions `98ish.notes.desk` and sort `98ish.notes.prefs` are device-only. Guests: "Only on this device"; the first sign-on adopts the notes, another account's book is set aside in `98ish.notes.acct.<key>` (like contacts). Recycle Bin 30 days (`purgeExpired`), then a purge tombstone. Shared notes can't be trashed for everyone: Delete = leave, a copy (new id) goes to your Recycle Bin. Desktop: stickies (react-rnd, under icons and windows) you can type/tick in; phones: a "Notes · N" panel bottom-left. Hold/right-click a card: Open, Pin, Color, Share, Delete. Search: provider type `notes`. Us hub tile "Our Notes" (handoff `{ filter: "us" }` / `{ newShared }`). Handoffs: `{ id, note }`.
    - **Server** `server/notes/` at `/api/notes` (bearer token): `POST /sync { since, notes }` (merges each, returns everything changed for you since `since` + `gone` ids you left + per-note `rejected`), `/:id/share { to }` (buddy must exist, not blocked either way), `/:id/leave { copy, trash }`, `/:id/unshare { key? }` (owner; removed people get a personal copy). One MongoDB doc per note in `notes` (`members`, `gone`, `names`, `data` JSON, `rev` optimistic). Live `notes:changed { ids, by }` to members' sockets; push category `notes` (15 min per note per person). Caps: 2,000 notes / account, 20 KB / note, 3 MB owned / account, 10 people / note, 200 notes per request; tombstones 180 days. Size: a doc is the note + ~200 B; typical notes 0.3-2 KB (20 people x 300 notes is about 10 MB of Atlas's 512 MB); the per-account 3 MB cap bounds the worst case. Delete My Account: personal notes go, shared ones stay with the others (owner passes on).
    - **Tasks** (`applets/tasks/`: `Tasks.jsx`, rules `tasksCore.js`). ONE SOURCE OF TRUTH: a task is a Calendar to-do event (`todo: true`) in any calendar (On this device / My Calendar / Us / a group = a shared task list): dated = all-day or timed event (start = end), Someday = a to-do memo, repeating = `repeat` with per-occurrence `done` exceptions (the next undone occurrence shows), `priority` ("high"/"low"/"", validated in `server/calendar/validate.js`), "For" = `attendees`. So sync, sharing, recurrence (`recur.js`), Calendar display and reminders (CalendarBridge in-app + server push) come for free; task reminders say "Task:" and open Tasks (push URL `?open=program&name=Tasks&cal=&event=`). Tasks also lists Calendar memos with checklists under Someday. Views Today (incl. overdue)/Upcoming/Someday/Done; a big Add task box (due follows the tab), the rest under More options. Search type `tasks` (to-do events left out of `events`). Tasks are capped by Calendar's 3,000 events per calendar (20 calendars).
    - Tests: `node --test client/src/components/applets/notes/notesCore.test.js`, `client/src/components/applets/tasks/tasksCore.test.js`; server `server/notes/test` (sync merge, shares, leave/unshare copies, blocks, push throttle, caps, erase). Browser `nt-desktop.mjs`, `nt-phone.mjs` (+ `nt-helpers.mjs`; vite 5386 / server 8386). Restart vite after edits before browser tests: HMR gives app modules a `?t=` URL, so `import("/src/utils/notes.js")` in a test would get a second instance.
  - **98ish Weather** (`applets/weather/`, program "Weather", Accessories, DOS `weather`/`forecast`): Open-Meteo (free, no key, CC BY 4.0; attribution in the status bar and About), called from the browser (`weatherCore.js` pure: URLs (metric always, `timezone=auto`, 7 days), WMO code -> icon/label (wind icon when dry and >= 40 km/h), °F/°C and mph/km/h, `shapeForecast` (now, 24 hours from the current hour, 7 days), places (`placeOf`: name + position rounded to 2 decimals, `id` "lat,lon"; max 12), cache freshness 30 min; `weatherStore.js`: fetch with a 12 s timeout, cache `98ish.weather.cache` per user, offline/busy/server errors keep showing the last forecast with its time, `searchPlaces` (geocoding API), `locate()` (geolocation from a tap; "My location")). Prefs in `utils/weatherPrefs.js` (`98ish.weather`: places, current, `tray`, `widget`, `widgetPos`; read eagerly by the taskbar/desktop without loading Weather). Units follow Regional Settings' new `region.temp` (`auto` = °F for US-style regions via `localeUsesFahrenheit`, `tempUnit()` in `utils/region.js`; Regional Settings tab has "Temperature:"; Weather's °F/°C buttons and View menu write it). Icons: original 32x32 pixel art drawn in code (`weatherArt.js` with `utils/pixelArt.js`: discs lit from the top left, black outlines, `toSvg`), rendered by `shared/PixelArt.jsx`; 14 icons (clear/partly/showers day+night, cloudy, fog, drizzle, rain, sleet, snow, storm, wind). The program icon `public/assets/program_icons/weather.svg` and the Control Panel's `cpl/dnd.svg` were written from the same drawings. Tray: `WeatherTray.jsx` (lazy, only when `tray`; icon + temperature, icon only on phones; click opens Weather, right-click Refresh / Hide; Taskbar Properties "Show weather"). Desktop panel: `WeatherWidget.jsx` (lazy `WeatherSpot` in Desktop.jsx; drag by its title bar, X removes it; on phones a small panel above the icons). Severe-weather alerts are NOT included (no free source that covers every region simply). Tests: `node --test client/src/components/applets/weather/weather.test.js`; browser scripts `wd-weather.mjs` (mocked Open-Meteo via `page.route`: place search, °F/°C, two places, tray, widget, cache, offline (route aborted; `context.setOffline` makes vite's dev client reload), phone 390x844), `wd-real.mjs` (one real request each to the forecast and geocoding APIs from Node), `wd-dnd.mjs`, `wd-sched.mjs` (`page.clock`), `wd-cpl.mjs` (entry points), helpers `wd-helpers.mjs`.

**Camera + Photos** (`applets/camera/`, `applets/photos/`; Accessories, also Entertainment, on the desktop):
- **Camera:** front/back/webcam via getUserMedia with clear permission/insecure/no-camera messages and a `capture` file-input fallback. Modes: Photo, Burst, Photo Strip, Video (clips download to the device; too big for the 98ish drive; on iPhone they record the plain camera without effects). 13 pixel effects + 9 frames. Photos save as JPEG (max 2048 px, about 600 KB; the camera asks for 1920x1440) into `C:\My Pictures`, and the status bar shows the drive's free space.
- **Photos:** folder grid, viewer with zoom (buttons, wheel, pinch, double-tap) and swipe that never moves the page, rotate, crop, brightness/contrast, effects/frames with Undo until Save, slideshow with transitions, Share (wallpaper, Paint, Photo Puzzle, Mail attachment, Network Neighborhood, download), rename, delete, upload (HEIC gets a message).
- **Opening any picture now opens Photos** (not Paint); right-click > Edit opens Paint. One-copy programs brought forward now still get a `handoff` payload (App.jsx), used by Puzzle and Mail.
- The drive now lives in IndexedDB (hundreds of MB; see Storage and sync), so hundreds of photos fit.

**98ish Calendar + Clock** (TimeTree-style shared calendars; not yet tried on a real phone):
- **Client:** `applets/calendar/` (Accessories, also in Us). `store.js` holds calendars and events (server calendars plus "On this device" in localStorage, uploadable); `recur.js` is the date math (repeats expanded client-side in the event's own IANA zone, so DST is right; exceptions keyed by the occurrence's original date); `ics.js` writes .ics files (the server imports it for feeds); `CalendarBridge.jsx` (lazy, always mounted on the desktop) applies live `cal:*` notices, fires reminders (Reminder window, Snooze/Dismiss, `98ish.cal.reminders`), rings Clock alarms and the timer, and opens Calendar/Clock (`openCalendar()`, `?calendar=CODE` invite links). The taskbar clock still opens Date/Time Properties on a double-click; right-click or hold it for Calendar and Clock.
- **Server:** `server/calendar/` at `/api/calendar` (Messenger bearer token; non-members get 404). Personal calendar per account, an "Us" calendar per paired couple (visible only while paired), group calendars with owner/member roles, invites by screen name or 8-letter code, comments, an activity feed, and a secret per-member iCalendar feed (`/api/calendar/feed/<token>.ics`) phones can subscribe to. MongoDB collections `calendars`, `calevents`, `calcomments`, `calactivity`.
- **Reminders with 98ish closed:** Web Push (see Notification Center above) sends reminders from server calendars ("On this device" calendars only remind while 98ish is open). Also: "Add to my phone" downloads an event's .ics, and Calendar Properties > Phone gives a webcal link (turn off "Remove Alerts" on iPhone for alarms).
- **Tests:** `node --test client/src/components/applets/calendar/recur.test.js` (and `ics.test.js`); server `server/calendar/test`; browser scripts `cal-*.mjs`.
