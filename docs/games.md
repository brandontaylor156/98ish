## Game performance (wave 1, 2026-10-04)
- **The clock rule:** a game loop measures real time with `utils/frameClock.js` (`createFrameClock().tick(rafTime)`). Keep `last` across frames; `reset()` only when the loop starts again after a stop (start/resume, resize, context restore, the tab coming back), never in the per-frame reschedule. (Pickleball and SPECTRA reset it every frame, so every frame counted 16 ms: half speed at 30 fps, double at 120 Hz.) Long frames clamp at 100 ms. Pickleball's physics already runs fixed 1/240 s steps (`match.advance`); SPECTRA's `logic.step` takes at most 50 ms, so the engine splits a frame into `substeps(dt, 1/30)` and handles events after each. Test: `node --test client/src/utils/frameClock.test.js` (clock + resolution); browser `hz.mjs` (rAF shim at 120/60/42/30 Hz) in the wave1 scratchpad.
- **Dynamic resolution:** `utils/dynamicResolution.js` (`createResolution({ max, min: 1 })`, fed each frame's interval and main-thread work): a 0.25 step down when a 2 s window averages 15% over the target (16.7 ms, or 33.3 ms on a device capped at 30 fps: steady ~33 ms frames with little work), back up after 3 good windows (6 when retrying the ratio that last failed); floor 1.0. Used by Pickleball (max = the quality's ratio: Low 1, Medium 1.5, High 2) and SPECTRA.
- **Anti-aliasing and DPR caps:** Pickleball, SPECTRA and Shred create their renderers with `antialias: true` everywhere; SPECTRA and Shred draw a 2x/3x screen at 1.5 (with AA that's sharper than 2 without, and cheaper). Canvas 2D games cap devicePixelRatio at 2 (Downhill/Ski, Pinball; Hover, Town, Dollhouse already did): a 2D canvas costs by the pixel.
- **Shaders compiled ahead:** Pickleball calls `warm()` (`renderer.compileAsync(scene, camera)`, KHR_parallel_shader_compile) after any change that brings new programs (venue + its lights, figures, athletes loading, quality, the Locker Room figure). While it compiles the last picture stays up (not during a match: that frame waits as before); the first warm-up is behind "Loading the court..." (`engine.ready`). `renderer.debug.checkShaderErrors` is dev-only (the info-log reads made every compile block). A venue switch went from a 0.9-1.3 s long task to 0.3-0.4 s (what's left is building the venue on the CPU). Athletes are still built in one go at Play (~60-100 ms; spreading them over frames would need placeholder figures or touching athlete.js).
- **Look:** the sky shader ends with `#include <colorspace_fragment>` (any custom ShaderMaterial must, or its colors come out darker than designed). Shadows (Medium/High): 2048 map, PCF radius 3, shadow camera fitted to the court + run-off as the light sees it (`fitShadow` in venue.js); every quality adds a small dark contact blob under each player's feet (Low has no shadow map). The big screen shrinks long names to fit and goes blank on an upright phone, where the HUD score panel covers it (`venue.setScreenCompact`).
- **Per-frame waste:** gamepads are polled only after `gamepadconnected` (or a pad already known at start); the touch stick's knob moves by a ref, not React state; meter CSS variables and data attributes are written only on change; the ball trail writes its typed arrays directly; replay copies only while recording. Desktop: `selectActive` skips the dispatch when the tapped window is already the one active window, and the `select_active` reducer returns the same state when nothing changes (pointerdown handling 26-42 ms -> 1-5 ms in a production build).
- **WebGL context loss:** `utils/webglLoss.js` `releaseGpu(scene)` in the `webglcontextlost` handler (Pickleball, SPECTRA) disposes GPU resources while the context is gone, so nothing is deleted against the restored context ("object does not belong to this context").

## Retro art (the quick games' look; use it for any new game that should feel 90s)
- **Rule:** no smooth vector shapes, gradients, system fonts or flat modern panels inside a game. Draw into a small logical screen in palette indices, blow it up by WHOLE device pixels (`image-rendering: pixelated`), shade with ordered (Bayer) dithering, use the pixel font, 98 bevels drawn at the game's pixel size, chip sounds. Window chrome (menus, GameStart buttons, 98 dialogs) stays as it is.
- **Kit, pure (`utils/retro/`, Node renders the same pictures; tests `retro.test.js`):** `palette.js` (`createPalette([[name, hex]...])`, index 0 = clear, `ramp()`, `lut` / `lutWith()` for flashes and palette cycling, `nearest`, `remapTable` + `tint` for icy/grey/dark remaps, `WIN16`, `vga256`, `UI_COLORS` every game palette starts with), `dither.js` (Bayer 2/4/8, `rampAt`), `bitmap.js` (indexed framebuffer: rect/line/ellipse/polygon/paint, `gradientV`, `shadeDisc` dithered spheres, `blit` with remap/mask (screen-door transparency)/flip/scale, clip, `bevel`/`well`, `present`), `font.js` (original 5x7 proportional font with descenders, `drawText` with shadow/outline/scale, `wrapText`, `drawTitle` chunky logos with dithered fill + outline + extruded shadow (use capitals), 7-segment `drawLed`), `sprite.js` (sprites as strings + legend, outline/recolor/flip/rotate), `fx.js` (8-frame `explosionFrames`, `sparkleFrames`, particles), `fit.js` (`fitPixels`: biggest whole number of device px per game px that still gives `minW x minH`), `ui.js` (98 buttons, LED counters, panels, segmented meters), `chip.js` (pulse-wave Fourier terms, 60 Hz stepped envelopes/sweeps, 15-bit LFSR noise).
- **React side (`shared/retro/`):** `useRetroScreen({ layout, render, palette, deps })` + `<RetroStage>` (canvas + invisible `<Hit>` boxes in logical px: real buttons/divs keep focus, keys, a11y, data attributes and test selectors), `paint()` from the game loop. Pieces for DOM overlays at the game's pixel size (`--px`): `PixelText`, `PixelLed`, `PixelArt`, `PixelButton`, `RetroPanel` (stage is `isolation: isolate` so panels never cover the menus), `RetroPaused`, `PixelScores`, `Sr` (visually hidden words), `RetroBanner` (30 fps attract loop for GameStart's `title`, still under Reduce Motion). `ScoresDialog` draws its tables with `PixelScores`.
- **Each game:** `pixels.js` (palette, sprites, `layout()` shared by drawing and hit boxes, `draw*()`, `drawBanner()`), previewable in Node. Re-render React only when something in the DOM changes (a signature, or once a second); the canvas paints itself every frame from a `live()` getter. Per-frame React renders while a panel is open made Chrome's touch emulation drop taps.
- **Sound:** `utils/gameSynth.js` chip voices: `pulse(freq, { duty: .125/.25/.5, to, vib, hold })`, `tri()`, `chipNoise({ pitch, toPitch, short })`, `jingle([[midi, beats]...])`, `arp()`, `hold(freq, { duty })`; all through the shared bus.
- **3D (Tetherball, `scene.js`):** renderer at the fitted low resolution, no AA; `retroize(material, U, { door, snap })` patches shaders (vertex snap to the pixel grid, 24-level Bayer-dithered quantize at the end of every fragment, screen-door alpha; door materials stay `transparent` or three.js forces alpha to 1); flat shading, low-poly, `DataTexture`s drawn with the kit (nearest), sprites for scenery; flat ground layers by `renderOrder` without depth and without snapping (else z-fighting/tearing).
- **Measured (iPhone emulation 390x844 @3x, dev build):** 54-60 fps at 4x CPU throttle in all five; per-frame drawing 0.06-0.9 ms in Node.

## Pinball: Blue Screen (2026-10-04; rebuilt from Deep Sea Dive)
- **Look:** authentic mid-90s PC pinball pixel art. The table is a 280 x 500 software-rendered buffer (half a table unit per pixel): `pixel.js` (palette of ~60 VGA-ish colors, Uint32 surface, Bayer-dithered `rampAt`, sprites from strings, 5x7 + 3x5 bitmap fonts, no anti-aliasing anywhere), `art.js` (`buildArt()`: base layer, lamp sprites lit by palette swap, ramp plastic overlay, taskbar apron overlay, Start-button bumpers, keycap targets, chrome balls), `render.js` (`createDrawer()` is DOM-free: Node renders PNGs; `createRenderer` puts the buffer on a canvas: 1:1 with CSS `image-rendering: pixelated` when a whole number of device pixels fits (>= 88% of the space), else prescaled 2x (or floor) nearest and eased by CSS). `dmd.js`: orange dot-matrix display (128x32 on a computer's side panel, 128x16 on a phone's top bar; `dmdContent` is pure). Window chrome stays plain Win98 (no gradients).
- **Table** (`table.js`, 560 x 1000 units, layer 0 playfield + layer 1 ramp): M-S-G top lanes (skill shot + lane change), 3 Start pop bumpers, left/right orbits with one-way gates into the inlanes, Hourglass spinner (left orbit), upper-left flipper (left button), Floppy drive saucer, slanted 9-8-I-S-H drop bank, Blue Screen lock scoop in a monitor behind it, Hard Drive captive ball, My Computer ramp (up, U turn, down to the right inlane), slings, Restore kickback (left outlane), taskbar apron with the Recycle Bin drain.
- **Physics** (`physics.js`): fixed 1/240 s steps split so nothing moves > 0.3 ball radius per substep (conservative CCD, tested at MAX_SPEED against thin walls/arcs/gates); uniform-grid broadphase per layer; kinematic flippers with angular acceleration (surface velocity transfer, sweet spot, live catch); spinners; layer transitions (lines crossed in a direction, with a margin) + `zones` (a ball outside the ramp area drops to layer 0); slopes (capsule regions with extra acceleration); `only: "captive"` colliders/sensors. Saucers add their sensor to `b.inside` when holding (no recapture on release); ball search kicks a ball still for 6 s.
- **Rules** (`game.js`): 8 missions (Dial-up, Virus Scan, Defragment, Send an IM, Save to Floppy, Surf the Web, Disk Cleanup, Install Update) ranking Intern -> Sysadmin, loops with bigger goals; extra ball lit at ranks 3 and 6 (Floppy collects); virtual locks (3 -> multiball, ramp jackpots, scoop super jackpot); ball save 8 s; tilt; bonus x lanes. High scores: top 10 with initials in `98ish.pinball.scores` (per user via the storage seam; `migrateScores` keeps Deep Sea Dive's list).
- **Controls:** keys Z/Left Shift/Left, Slash/Right Shift/Right, Space/Down/Enter plunger, X . Up nudge; touch halves of the table (multi-touch), drag the plunger down (or HOLD button), NUDGE button, shake; gamepads polled only after `gamepadconnected`. Loop on `utils/frameClock.js`; no shake with `reducedMotion()`.
- **Tests:** `node --test client/src/components/applets/pinball/pinball.test.js` (29: CCD, layers, flipper/bumper/sling/spinner, ramp made/failed, orbit, launch gate, captive, rules, DMD, palette-only frame). Scratchpad `pin/`: `pin-phone.mjs [pro]` (CDP multi-touch, plunger drag, layout at 390/430), `pin-bot.mjs desktop|phone [throttle] [s]` (bot through the input path, multiball + mission shots, fps), `snap.mjs` (Node PNGs), `bot.mjs` (headless games). Measured: desktop 60 fps (update 0.3 ms, draw 1.1 ms); phone at 4x CPU throttle median 16.7 ms (draw 5.4 ms). Screenshots in `shots/pinball/`.

## Chess Puzzles (2026-10-05)
- **What:** `applets/chesspuzzles/` (own program, "Chess Puzzles"; Chess's Game menu has **Puzzles...** via `useNet().openProgram`). Lichess-style trainer: the data's first move is the opponent's (slides in), then the player finds the line; each right move gets the reply; **any checkmating move counts** (like Lichess). A wrong move flashes red and is taken back (`tryMove` keeps the board), the puzzle is marked failed; Retry / View solution (plays the line step by step) / Skip.
- **Modes:** Rated (Glicko-1 rating, start 1500/RD 350, RD floor 60, puzzle RD 80; "?" while RD > 110; a hint makes a solve unrated, a mistake or the solution counts as a loss), Puzzle Streak (`streakTarget(n) = 900 + 60n`, one mistake ends it, one skip), Puzzle Rush 3 min / 5 min / Survival (`rushTarget = 700 + 75k`, 3 strikes), Daily Puzzle (FNV hash of the date over ratings 1300-2099), 33 themes (`THEMES`; "mate" = any mate theme), History with Replay (unrated). Baseline: board, Hint/Next, rating; modes, theme, history and reset under More options (and the Game menu).
- **Data:** 4,087 puzzles from the Lichess puzzle database (CC0, database.lichess.org, `lichess_db_puzzle.csv.zst`, 2026-10-02 dump), quality-filtered (RD <= 85, popularity >= 85, >= 300 plays), ~185 per 100-point bucket from 600 to 2800, picked greedily for theme variety. Five shards by rating band (`puzzles/band0..4.js`, a string of `id,FEN,moves,rating,themes` lines; 516 KB raw, ~197 KB gzip), dynamic imports so they're separate chunks; the band for your rating loads first. Rebuild: stream the .zst with Node 24's `zlib.createZstdDecompress()` after stripping pzstd skippable frames (Node rejects them), sample, write shards (scripts were in the session scratchpad: `sample-puzzles.mjs`, `build-puzzles.mjs`).
- **Code:** `puzzleCore.js` (pure: `parseShard`, `startPuzzle`/`playSetup`/`tryMove`/`playReply`/`stepSolution`/`retry`/`hint`, `choosePuzzle` widening windows and skipping seen ids, `dailyPuzzle`, `rate`), `PuzzleBoard.jsx` (tap-tap and drag like Chess, slide animation, hint/wrong squares, promotion picker), `ChessPuzzles.jsx`. Uses `network/rules/chess.js` (castling, en passant, promotion all verified by playing every bundled line). Progress per user in `98ish.chesspuzzles` (rating, history 150, seen 2,500, bests). Dev hook `window.__chesspuzzles`.
- **Tests:** `node --test client/src/components/applets/chesspuzzles/chesspuzzles.test.js` (8: every bundled line legal to the end, mate alternative, promotion piece, castling/en passant, multi-move with replies, hints, choosing/themes/daily, rating). Browser `cp.mjs` (desktop + 390x844 touch: setup move, hint, tap/drag solves, rating up/down, wrong move, solution, Rush, theme, Chess menu).

## Imposter (2026-10-05)
- **What:** `applets/imposter/` party word game: everyone but the imposter(s) gets the secret word; clue rounds, discussion, vote; a caught imposter may name the word to steal the round. Pass-and-play (`local.js` runs `rules.js` in the browser; "Pass the phone to X" gates before anything private: cards, secret votes, the guess) and online (`server/arcade/games/imposter.js` loads the same `rules.js`; the server picks word and imposters, each view carries only that player's card; the result reveals). No computer players (a word game bot would need clue data): `onLeave` drops a player (their clue turn passes; an imposter leaving gives the crew the round; < 3 players ends the game). Room seats 3-20 (`rooms.js` now allows maxPlayers up to 20).
- **Rules/settings** (`DEFAULTS` in `rules.js`, all validated): imposters 1-9 capped at (n-1)/2, random count, % chance of none (forces "No imposter / skip"), imposters know each other; imposter's card none/category/hint/decoy/undercover (close word, not told); crew sees category; 28 categories (`words.js`, "Word:Close word" pairs, family-friendly, trademarks avoided) + custom words (<= 60, "word:close"); clues spoken (tap Done) or typed (crew can't type the word: `saysWord`), 1-5 rounds, clue clock; discussion none/until ready/clock; votes secret/open/group (one shared pick), vote clock (missing votes abstain), skip, ties revote/noone/random/all, once vs elimination; guess when caught/any time (wrong = crew wins)/never, pick from 8 or type (loose matching: case, accents, plurals); starter random/rotating, imposter never first; scoring (crew +1, +1 for voting an imposter; imposter +2 escape, +3 naming the word; no-imposter round +1 for each "no one" vote), length rounds/score/endless, reveal roles. Presets Classic, Quick, Undercover, Chaos. Timers use `ctx.after(ms, { type: "timeout", stamp }, "phase")`; a stale stamp does nothing.
- **UI:** setup = player names + Start (+ Play Online); every knob in `SettingsForm.jsx` under More options (also the online room's settings). `Table.jsx`: `OnlineTable` (Got it, speaker's Done/typed clue, Ready to vote, vote buttons, Show my card, I know the word!) and `LocalTable`. Sounds `sounds.js` on the shared bus. Saved per user in `98ish.imposter` (names, local + online settings). Dev hooks `window.__imposter` (local game), `window.__imposterView` (online view).
- **Tests:** `node --test server/arcade/test/imposter.test.js` (17, in root `npm test`: settings, roles/views hide cards, variants, turn order and word check, guess phase, steal, wrong vote, ties, zero imposters, group vote, elimination, anytime guess, timers, length, leaving, matching, a 3-player room). Browser `ip.mjs` (pass-and-play at 390x844 touch and desktop through a full round + Chaos preset; three phones online with typed clues, checking the imposter's browser never receives the word).

## Critter Catch Pinball (2026-10-05; the owner asked for "Pokémon Pinball with actual Pokémon")
- **Why not Pokémon:** Nintendo/Game Freak IP; per the trademark rule it's an original tribute: the GBC game's mechanics (catch, evolve, map moves, Dex, bonus stages, ball upgrades, an outlane saver) with 98ish's own 47 critters. Program "Critter Catch Pinball" (`applets/critterpinball/`, app `critterpinball`), separate from Blue Screen but reusing its `physics.js`, `pixel.js` (21 palette colors appended: purples, browns, handheld greens...), `dmd.js` (`createDmd(..., colors)` for the green LCD), `art.js` helpers (`capsule`, `post`, `paintLamp`, `windowDecal`, exported) and `render.js` (`drawFlipper`, `drawPlunger`, `drawBallAt`, `roll`, exported). Not the `utils/retro` kit, on purpose: same pixel look and code as the other pinball.
- **Critters** (`critters.js`): 23 Ember + 21 Tide + 3 bonus bosses, 13 types, evolution lines up to 3 stages (stage 3 only by evolving), `areas: { area: rarity }` (common 10 / uncommon 4 / rare 1; a better ball boosts uncommon/rare), Dex lines. Six areas per table; the last three ("far": rares) open after 3 map moves in a game. `sprites.js` draws every critter from a spec (body plan round/pear/quad/bird/fish/serpent/ghost/bug/rock/jelly/crab/turtle/plant + ears, tail, eyes, markings, size), 32x32, shaded and dithered, ink outlines; `critterSprite(c)` caches. `cry.js`: a cry per critter from its id.
- **Tables** (`layout.js`): Blue Screen's skeleton, ramp, orbits and gates; Tide mirrors Ember's playfield (ramp left, spinner right, Den/Cave swapped) with its own bumper triangle. Features: 3 upgrade lanes, 3 bumpers, spinner (charges Sparkit), ramp, orbits, E-V-O drop targets, Den and Cave saucers, the critter collider in the middle (`active` only while one is out), the center "CRITTERS" window with a green LCD screen (area picture, the reveal tiles, the critter to evolve). Bonus worlds (`buildBonus`): closed dome, no shooter lane; Burrow Bash (Mudpups pop up, 8 then Grandmole x3), Phantom Hall (Wispurr drifts and fades), Tidal Titan (Krabaron sidesteps, claws block). Bosses drawn 2x with matching colliders; moving ones are `dynamic` colliders with velocity.

E-V-O -> Den: flippers choose among this game's catches (both flippers / Space / 8 s), 3 lit item shots, Den evolves (replaces it in `g.caught`). 3 ramps -> Cave map move. 3 catches/evolutions -> Cave bonus stage (draining there costs no ball). Lanes upgrade Basic/Super/Hyper/Master (1/2/3/5x, a minute each, drops a level on drain). Sparkit saver charged by 12 spins, flippers move it. Extra ball at 5 and 10 critters in a game; ball save 10 s; tilt. `g.dexEvents` -> the component saves `98ish.critterpinball.dex` (per user, storage seam); high scores per table `98ish.critterpinball.scores.<table>`. - **UI** (`CritterPinball.jsx`, `lcd.js`, `Dex.jsx`): Blue Screen's chrome (imports `Pinball.css`) with a green LCD; start screen = table picker + Play, More: Critter Dex / High Scores / How to Play; menus Game (tables, Dex, scores), Options, Help. Dev hook `window.__critterpinball` (`game()`, `G`, `dex()`, `perf`, `newGame`, `chooseTable`).
- **Tests:** `node --test client/src/components/applets/critterpinball/critterpinball.test.js` (24: data/sprites/evolution lines, spawns, Dex, letters, catch, cooldown, timeout/drain, evolve, map unlock, bonus stages, moving bosses, Sparkit, upgrades, extra ball, drains, shot reachability for critter/Den/Cave/ramp on both tables, 4-min bot per table with no escapes, bonus walls, palette-only frames, LCD, cries).
