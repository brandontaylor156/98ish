# Visual Basic 98 (2026-10-06)

The owner approved "Visual Basic 98 + apps in messages" from the groundbreaking list (research: `scratchpad/research/github-inspiration.md` §2 webxdc, §7, idea #4). A drag-and-drop app builder in the classic VB look: friends make little programs and games, and **send them in 98 Messenger**, where they run on everyone's 98ish with **Shared** values kept in step (webxdc-style).

## What it does
- **Designer** (`applets/vb98/Designer.jsx`): Toolbox (Label, TextBox, CommandButton, CheckBox, OptionButton, ListBox, ComboBox, PictureBox, Shape, Sprite, Timer, Sound), a form you drop controls on (tap a tool, or drag it onto the form; a tapped tool lands under the others), drag to move, the corner handle to size (4 px grid), the form's corner handle sizes the form. Properties window (Name, Left/Top/Width/Height, Visible/Enabled, Caption/Text, colors with a picker, font size/bold, list items, pictures: an emoji or a photo shrunk under 120 KB). Renaming a control renames its event Subs and `Name.` uses in the code.
- **Code** tab: VB's Object and Procedure lists (picking an event adds `Sub Obj_Event()` and puts the caret inside), a monospace editor, live checking ("Line 2: There's no control or object called Label9"). **Blocks** tab: Blockly (Apache-2.0, lazy chunk ~213 KB gzip) with VB blocks; the blocks write the code (one-way: Switch to Typing Code keeps the code; Start Over with Blocks replaces typed code).
- **Run** (F5) opens the program in its own window (the same program, `handoff.project`). **File**: New, New from Template (Hello, Poll, Quiz, Tic-Tac-Toe, Reaction Time, Magic 8-Ball, Soundboard, Countdown, Star Jumper), Open (every .vb98 on the drive), Save/Save As (C:\Documents\Name.vb98, file type `vbapp`), Make Desktop Icon, Send in Messenger, Shared with Me. The unsaved project is a draft in localStorage `98ish.vb98.draft` (per user through the storage seam).
- **Phones**: Form / Code / Blocks / Properties tabs, the Toolbox as a row, bigger handles, the form scaled to fit.
- **Programs in a message**: Send... picks a buddy, a chat room you're in, or everyone in Come Over. The buddy's IM gets "X sent a program: Title." with **Open** (also a Notification Center item; a push with `?open=program&name=Visual%20Basic%2098&vbapp=<id>` if they're signed off); in Come Over it opens on everyone's desktop. The sender's own copy opens too, so both play the same instance.

## The language (`vblang.js`, pure)
A slice of VB6, compiled to async JavaScript that calls a runtime `R` (`vbruntime.js`, pure): Dim/Const/ReDim, arrays, If/ElseIf/Else (block and one-line), For/Next with Step, For Each, Do While/Until...Loop While/Until, While/Wend, Select Case (values, `To` ranges, `Is >`), Sub/Function with parameters, Exit Sub/For/Do, End, comments, `_` continuation and `:` separators. Case-insensitive. Undeclared variables that are assigned somewhere become module variables (VB without Option Explicit); read-only unknown names are reported as typos. Built-ins: Len, Left, Right, Mid, UCase, LCase, Trim, InStr, Replace, Val, Str/CStr, CInt, Int, Abs, Sqr, Round, Rnd, Random(a, b), Now, Time, Date, Timer, Chr, Asc, Split, Join, UBound, IsNumeric, RGB, Format, String, Space, DaysUntil, MsgBox, InputBox, Wait. Objects: controls by name (properties and methods: AddItem, RemoveItem, Clear, List(i), Move dx, dy, MoveTo, Touching(other), Play, SetFocus), `Form`, `Me.Name`, `Me.IsHost`, `Friends` (Count, For Each), `Shared("k")` get/set, `Shared.Keys`, `Sound.Play "tada"`. Events: `Control_Click/Change/Timer`, `Form_Load/Click/KeyDown(Key)`, `Shared_Changed(Key)` (runs for your own and friends' changes). Every Sub is async so MsgBox/InputBox wait.

## The sandbox (`srcdoc.js`, `sandboxBoot.js`, `bridge.js`, `Runner.jsx`)
- An iframe with `sandbox="allow-scripts"` (no allow-same-origin: opaque origin, no 98ish storage/cookies/DOM) and a CSP of `default-src 'none'` + inline script/style, `connect-src 'none'` (no fetch/WebSocket), images only `data:`/`blob:`. The page is `vbruntime.js` + `sandboxBoot.js` as text (Vite `?raw`), plus 98-style CSS. Verified in the browser test: origin "null", localStorage blocked, parent DOM blocked, fetch blocked.
- **Watchdog**: the compiler puts `R.tick()` in every loop turn and procedure call; an event that runs 2 s without waiting (MsgBox/InputBox/Wait reset the clock) is stopped with "This program stopped responding (an endless loop?)", the program ends; recursion over 200 deep is "Out of stack space". The parent also pings every second and offers **End Program** after 6 s of silence.
- **Bridge allow-list** (`bridge.js` `checkSandboxMessage`): only boot, ready, end, pong, sound (a name), set (a key matching `[\w .:\-#@!?+=]{1,64}`, a number/boolean/string ≤ 8,000), error (message ≤ 300, line). Everything else is dropped. Sounds play in 98ish (`vbsounds.js` on `utils/gameSynth.js`: taskbar volume/mute, "Play system sounds"). Runtime errors show a VB-style "Run-time error (line N)" box in the program.
- Scaling: the iframe is sized to fit (`scale` message), the program scales its own form, so taps land true.

## Server (`server/aim/vbapps.js`, `vbappStore.js`)
- Socket events on the 98 Messenger connection: `vb:share { app, with | room | hangout }`, `vb:open { id }` (program + state + people), `vb:set { id, k, v }` (relayed as `vb:update` to everyone else with it open), `vb:watch`/`vb:close`, `vb:mine`, `vb:forget`; server sends `vb:invite`. The program is re-checked with the client's `vbfile.js` (dynamic import). Who: the two in an IM (blocks refused), whoever is in the chat room (and anyone in the room later), the people in the Come Over hangout.
- Storage: MongoDB `vbapps` (memory without MONGODB_URI): `{ id, owner, members, names, title, conv, app, state, bytes, counts, createdAt, changedAt, expireAt }` with a TTL index (30 days after the last change). Caps: program 256 KB (`vbfile.js` MAX_BYTES; pictures 120 KB), Shared state 64 KB, values 8,000 chars, 200 changes a day per person per program, 30 shared programs per owner (`VB98_PER_OWNER`), 40 MB server-wide (`VB98_TOTAL_MB`); rates 10 shares/min, 40 sets/10 s. Saves batch 1.5 s after a change. Traffic is tiny (a Tic-Tac-Toe move is three ~100-byte messages).
- **Delete My Account**: eraser step "vb98 programs" (`vbapps.eraseAccount`): they leave every shared program (the next member owns it); one nobody else is in is deleted; Shared values they set stay (a vote, a move). Inventory line in `server/account/index.js`; Help privacy lines in `support.js`.

## Limits / next
- No control arrays, no `Option Explicit`, no classes/modules, no file or network access by design.
- Blocks → code is one-way; no procedure blocks yet. Blockly is ~800 KB (lazy).
- Shared state is last-write-wins per key (two people claiming X at once: one wins). The runner's program can't reach the 98ish phone keyboard (inputs inside the sandbox use the phone's own keyboard).
- KAPLAY wasn't needed: Sprites, Shapes and a Timer cover simple games; a canvas/KAPLAY control would be the next step for faster action games.
