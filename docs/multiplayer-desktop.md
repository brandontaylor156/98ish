# Come Over: the multiplayer desktop (2026-10-06)

The owner asked for a flagship, "a team would take years" feature. Come Over makes 98ish a multiplayer operating system: up to 4 people "hang out" on each other's 98ish. They see each other's pointers, visit each other's desktops, follow someone's view, hand each other files, and edit the same Notepad text, Paint picture or folder at once.

## What it does
- **Invite / join**: Come Over (Start > Programs > Internet, also Us) lists signed-on buddies; **Invite** sends `hg:invite`. The buddy sees an in-desktop card (Join / Not Now) plus a Notification Center item; if they're away, a push goes out in the `im` category with a deep link `?open=program&name=Come%20Over&hangout=<id>`. `interrupts("hangout", from)` respects Do Not Disturb. A hangout lives in memory and ends when the host leaves.
- **Pointers**: each person's pointer is sent as screen fractions, throttled to 15 Hz (`hangoutCore.throttle`), and glides on other screens (`glide`, half-life 45 ms). On phones a tap is sent instead and shows as a ripple. Each pointer has a name tag with the focused window ("· busy" for a private program). Drop a file from My Computer onto a name tag to hand it over.
- **Taskbar strip** (`HangoutTray`): a colored dot per person (drop target for files; menu with Follow, Visit, Let Friends Touch, Open, Stop Sharing and Leave) and a red **Stop**.
- **Visit** (Come Over > Visit, `VisitView`): a live copy of a friend's desktop made from snapshots they publish every 2 s when something changed (`desktopSnapshot`: wallpaper path/color, up to 40 icons, up to 16 windows as fractions). Look-only unless they tick "Let friends here open and switch windows on my desktop" (`hg:perm`); then tapping an icon sends `hg:act { open }` and tapping a window sends `{ focus }`, applied by the host's own layer (private programs refused).
- **Follow**: `hg:watch { key }`. The leader's layer sends `hg:view` (app, title, shared doc id, scroll fraction) every 300 ms when it changed and only while someone follows; the follower's layer focuses or opens the same program (for shared Notepad/Paint, the same document) and scrolls. A bar at the top says "Following X" with Stop.
- **Shared documents** (Yjs CRDTs): Notepad and Paint have **File > Share with Friends Here** (and Stop Sharing, keep a copy); Come Over > Share makes new ones; Come Over > Shared lists them. Notepad: `sharedText.js` turns each input into the smallest edit (`textEdit`), moves your caret through remote deltas (`throughDelta`), sends caret/selection as Yjs relative positions, and `RemoteCarets.jsx` draws friends' carets and selections on a see-through mirror of the textarea. Paint: `sharedPaint.js` keeps a shadow copy, and after each finished change (nothing being drawn) sends the changed pixels as runs (`diffPixels`/`packRuns`, a few hundred bytes per pencil line) into `Y.Array("ops")`; the picture is white + every op, so Y.UndoManager undo (yours only) redraws without your op. Over 400 ops or 1.6 MB of runs it flattens to one op (undo history ends there). A size change (Image > Attributes) resets the ops with the whole picture.
- **Shared with Friends folder** (`SharedFolder.jsx`): a Yjs doc whose `files` map holds each file as a data URL/text (1 MB a file, 6 MB a folder), added from Drive C:, by drag from My Computer, or from the device; opening puts a copy in C:/Documents.
- **Hand a file** (`hg:give`): up to 1.5 MB, 20 files per 10 minutes and 12 MB per hour per person; it lands on the receiver's desktop (`C:/Desktop`) with a notification.

## Privacy
- `PRIVATE_APPS` (client `hangoutCore.js`, server `server/aim/hangout.js`, keep in step) plus **default-deny**: a window with no program id (98 Messenger's Buddy List), any `aim-*` window, Mail, Notes, Tasks, Passwords, Photos, Camera, Address Book, Buddy Locator, Backup, Control Panel, lock/users, Watch Together and the couple programs are "Private window" with no title or icon in snapshots, "busy" in pointer tags, and "private" to followers. Windows without an `app` use their program's `type` (`appOf` in HangoutLayer). The server re-checks snapshots (`sanitizeSnapshot`: also only `/path` images), focus and views (`FOLLOW_APPS` allowlist).
- Hangouts are memory only. Shared documents: MongoDB `shareddocs` (memory without MONGODB_URI). Delete My Account step "shared documents" (`ydocs.eraseAccount`): docs only they're in are deleted; in shared ones they leave and the next member becomes owner (their edits stay part of the CRDT). Inventory line in `server/account/index.js`; Help `come-over` + privacy lines in `support.js`.

## Server (`server/aim/`)
- `hangout.js`: `createHangout({ sessions, hidden, emitTo, limiter, pushTo, ydocs })`, wired in `index.js` like Watch Together (`bind(on)`, `dropped` keeps a place 30 s, `resumed`, `blocked`, `leave` on sign-off). Caps: 4 people, 200 hangouts, 8 invites/min, presence 25/s, views 50/10 s, desks 12/10 s (12 KB each), acts 20/10 s.
- `ydocs.js` + `ydocStore.js`: the relay. `yd:open { id, sv }` returns what the client is missing plus the server's state vector; the client sends back what the server is missing (this handshake runs on every open and every reconnect, which is how offline edits merge). `yd:up` updates are applied to the server's Y.Doc, relayed to others with it open, and saved 2 s after the last change. Caps: per update 1.5 MB, per document text 512 KB / paint 3 MB / folder 6 MB, per owner 40 docs and 12 MB, server-wide 80 MB (`YDOC_PER_OWNER`, `YDOC_OWNER_MB`, `YDOC_TOTAL_MB`). Rates: 80 updates/10 s, 120 cursor updates/10 s, 10 creates/min. Docs unload 2 min after the last person closes them.
- Dependency: `yjs` (MIT) in root and client `package.json`.

## Client
- `utils/hangout.js` (store, actions, `HANGOUT_EVENTS`; dev hook `window.__hangout`), `utils/ydoc.js` (`openShared`, `createShared`, `YDOC_EVENTS`; 40 ms batching with `Y.mergeUpdates`; dev hook `window.__ydoc`); both attached by `AimContext` (it passes `emit` for no-ack sends).
- `applets/hangout/`: `Hangout.jsx` (window: Here / Visit / Shared; More options: touch permission, traffic numbers), `HangoutLayer.jsx` (mounted in `Desktop.jsx` for phone and computer), `HangoutTray.jsx` (TaskBar), `VisitView.jsx`, `SharedFolder.jsx`, `RemoteCarets.jsx`, `sharedText.js`, `sharedPaint.js`, `hangoutCore.js`, `Hangout.css`. Notepad and Paint take a `handoff` ({ shared, title }) from Desktop. Phone windows now carry `data-window-index` like desktop ones.
- Registered: programs.js, DOS `comeover`/`hangout`, Task Manager, Floppy, drive, imageMapper, Add/Remove, notifications app `hangout`, deep link `hangout=`, icon `hangout.svg`.

## Measured (browser run, 2026-10-06)
- One person moving the mouse non-stop for 20 s: 0.41-0.45 KB/s up, 0.61-0.68 KB/s down at the other end (about 27 KB a minute). Idle (nothing moving): 0-3 B/s. A 2-person session is well under Render's budget even for hours.
- A pencil line in shared Paint: ~60-100 bytes of runs; typing in a shared note: tens of bytes per keystroke batch.
