# Sharing with the phone (Web Share, share target, clipboard)
Moved from CLAUDE.md on 2026-10-05.

  - **Sharing with the phone:**
    - Out: `utils/share.js` `shareOut(payload, "phone" | "apps")` (Web Share API; call it straight from the tap, no awaits first, or iOS refuses) with fallbacks: download the file, or copy the text (a 98 message via `ShareCenter`). Payload rules are pure in `utils/shareRules.js` (tested: `node --test client/src/utils/shareRules.test.js`). "Send To > My Phone / Other Apps..." is in My Computer, desktop files, Notepad, WordPad, Paint, Sound Recorder, Photos' Share menu, Camera (File menu + a Share button after a shot), Calendar event "Share..." (.ics), Speed Typist "Share Result...", Word Duel "Share..." (plus "Copy"). `MenuBar` now supports submenus (`items` on an item).
    - In: `manifest.webmanifest` `share_target` (POST multipart to `/share-target`) -> `public/sw.js` keeps it in the `share-inbox` cache (not `98ish-*`, so updates don't clear it) and redirects to `/?share-target=<id>`; `OS-specific/ShareCenter.jsx` (lazy, on the desktop) shows **Received Items** and saves via `utils/receive.js` (pictures -> JPEG in My Pictures, audio -> whole Music 98 songs (type `song`, no 30 s cut; `docs/together-music.md`), other files -> My Documents, links -> desktop Internet Shortcut and/or IE, text -> a Notepad document). GET `/share-target?title&text&url` works too (vercel.json rewrite for no-SW visits). **Only Android Chrome (installed app) and ChromeOS can be share targets; iOS Safari can't** (WebKit bug 194593, open as of 2026). iPhone path: "Upload from Phone..." (desktop right-click, My Computer File menu + toolbar Upload) and Paste.
    - Clipboard: `utils/systemClipboard.js`. Copying a file in My Computer/desktop (`fsActions.setClipboard`) mirrors its words / URL / picture to the system clipboard; Paste with nothing copied in 98ish (and "Paste from Device Clipboard") reads the system clipboard (pictures, links, text); Ctrl+V / the phone's Paste use the paste event. Notepad/WordPad Cut/Copy fall back to the Clipboard API.
    - Browser tests: `share-*.mjs` against `vite build` + `vite preview` (the SW needs a production build).
